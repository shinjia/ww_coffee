# mis_feedback 客戶意見留言子系統

## 用途

提供對外開放的客戶意見表單，以及登入後供員工及管理者處理留言的管理介面。

## 公開功能

- 姓名、Email、類別、留言與聯絡資料使用同意。
- 前後端雙重驗證、CSRF、蜜罐欄位、開啟時間檢查及 Session 頻率限制。
- 非同步送出時顯示載入中、成功、查詢編號及錯誤狀態。
- IP 僅以每月加鹽雜湊形式保存，不保存原始 IP 於留言資料。

## 內部功能與權限

- `employee`、`admin`：登入後查看最新 200 筆留言及狀態摘要，將留言設為新留言、處理中或已結案。
- 所有狀態變更寫入 `audit_logs`。

## 資料

使用共用 SQLite 的 `feedback` 資料表，保存查詢編號、客戶姓名、Email、類別、內容、狀態、IP 雜湊與時間。

## 已知限制

- 尚未提供附件、Email 自動通知、搜尋、分頁、刪除或資料保存期限清理。
- Session 頻率限制只能降低一般重複送出；正式上線仍建議加上 Web Server／WAF 層級的流量限制。
- 上線前需補充完整隱私權政策、資料保存期限與客戶聯絡處理流程。
- 已實測格式錯誤回傳 HTTP 422、有效留言回傳 HTTP 201 與查詢編號；測試留言已清除。
